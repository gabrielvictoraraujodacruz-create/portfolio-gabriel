Inside the projects

A plain-language, step-by-step look at how the main parts work. I built everything with Claude Code; this is what I need to understand to explain, test and fix it.

  1. The HTML: a box where answers appear and a form with a text field.
  2. The event: pressing Enter makes the form fire a submit. JavaScript listens with addEventListener and calls preventDefault() so the page does not reload.
  3. The command list: an object where each name points to a function. help returns the list, about scrolls to the section, and so on.
  4. Running it: the typed text is lowercased and the code looks that name up in the object. If it exists, it runs the function; if not, it answers “Command not found”.
  5. Showing the answer: createElement creates a new paragraph, sets the text and append adds it to the box.
  6. Extras: ↑ and ↓ walk through the history (an array of what was typed), Tab completes the command name and the secrets you find are saved in localStorage.

  1. The board: a 320 × 320 <canvas> split into 16 × 16 squares of 20 pixels.
  2. The snake is a list: [{x: 8, y: 8}, {x: 7, y: 8}, {x: 6, y: 8}]. The first position is the head.
  3. Moving: on every step, the new head is the current head plus the direction. It goes into the start of the list (unshift) and the last position comes out (pop). That is why the snake seems to move.
  4. Eating: if the head lands on the fruit, the code does not remove the last position, so the snake grows by one square. A new fruit is placed on an empty square.
  5. Losing: if the head leaves the board or hits the body, the game ends and the high score is saved in localStorage.
  6. Controls: arrow keys and WASD (keydown), on-screen buttons and swiping (pointer events) change direction. Turning back on itself is blocked.
  7. Smoothness: requestAnimationFrame draws about 60 times per second, and between steps the snake is drawn partway along its path.
  8. The bug I found: the fruit grew in with a size based on time. On phones the math sometimes went negative, the canvas threw an error and the game froze. The fix was to never let it go below zero: Math.max(0, ...).
