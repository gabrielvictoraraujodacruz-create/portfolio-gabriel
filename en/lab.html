Unit 4 · Versioning, deploy and accessibility

commit
A snapshot of the project at one moment, with a message saying what changed.
branch
A parallel line of work, to try something without touching what already works.
pull request
A request to merge a branch into the main one, with room for review.
deploy
Putting the site online. This one runs on GitHub Pages: every git push publishes it again.
WCAG
The web accessibility guidelines, such as minimum contrast between text and background.
ARIA
Attributes that tell screen readers what each element does.

Accessibility on this page

  • A “Skip to content” link (press Tab when the page opens)
  • Table with a caption and scope on headers
  • Color buttons with aria-pressed
  • Counter announced with aria-live
  • Animations turned off for people who ask for less motion
  • Light or dark theme, the same one you picked in the portfolio
