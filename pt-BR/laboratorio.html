Unidade 3 · JavaScript e componentes do Bootstrap

É a página transformada em objetos que o JavaScript consegue ler e mudar. O contador ao lado mexe no DOM a cada clique.

Guarda dados no navegador mesmo depois de fechar a aba. É assim que o portfólio lembra se você escolheu o tema claro, e que o contador ao lado não zera.

O Bootstrap entrega estilos e componentes prontos. React e Vue organizam a interface em componentes que se atualizam sozinhos quando os dados mudam.

Unidade 4 · Versionamento, deploy e acessibilidade

commit
Uma foto do projeto num momento, com uma mensagem dizendo o que mudou.
branch
Uma linha paralela de trabalho, para testar algo sem mexer no que já funciona.
pull request
O pedido para juntar uma branch na principal, com espaço para revisão.
deploy
Colocar o site no ar. Este aqui está no GitHub Pages: cada git push publica de novo.
WCAG
As regras de acessibilidade da web, como contraste mínimo entre texto e fundo.
ARIA
Atributos que explicam para leitores de tela o que cada elemento faz.
